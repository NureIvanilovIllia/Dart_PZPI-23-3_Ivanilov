# Dart_PZPI-23-3_Ivanilov

Лабораторні роботи з дисципліни “Програмування мовою Dart”, варіант 15 – технічне обслуговування автопарку. Кожна робота лежить у власній папці, це окремий пакет `fleet_service`.

- `LB1` – функції та обробка колекцій (записи й колекції, без класів);
- `LB2` – об’єктно-орієнтована модель тієї самої предметної області.
